About Project

Minor project methodology, dataset usage, backend engine, and evaluation

Project Title

Fake News Detector using Machine Learning

Objective

This project analyzes news content and classifies it as reliable, moderately reliable, suspicious, or highly suspicious using a hybrid backend engine.

Dataset Used

The system is trained using real-world labeled data from Fake.csv and True.csv. This improves realism and makes the backend stronger than a toy sample-based classifier.

Backend Engine

The system preprocesses input text, converts it using TF-IDF vectorization, compares machine learning models, selects the best model, and then uses hybrid credibility scoring. The final result is based on machine learning confidence, source reliability, keyword risk, content quality, and similarity with known fake and real news patterns.
